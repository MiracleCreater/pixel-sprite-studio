# MyPixelTool 使用说明

自制像素动画流水线（与 PixelSmith 功能相同的核心链路，全部基于开源组件，无需激活码）。

## 流程

批量出候选图（Qwen-Image 2.1 Turbo）→ **你挑选一张** → 图生视频（MiniMax H3 8步）→ 去背景（RMBG 2.0）→ 像素化 → **你确认接受 → 才写入硬盘**

## 网页界面（推荐）

**双击 `启动网页界面.bat`**，浏览器自动打开 http://127.0.0.1:8899

### 第一次用：跟着「新手引导」走

第一次打开会自动进入 `/wizard`（之后随时可以点右上角「新手引导」重新进）。它把「能不能跑」拆成 6 步，**一次只问你一件事**：

| 步骤 | 检查什么 | 不通过时你自己能做什么 |
|---|---|---|
| 1 程序文件 | ComfyUI 主体、内存暂存节点在不在 | 提示你重新解压 / 覆盖哪个文件夹 |
| 2 显卡与驱动 | 有没有 N 卡、显存多大、驱动版本 | 告诉你去装哪个驱动；没显卡就给你局域网方案 |
| 3 模型文件 | 缺哪些模型、还差几 GB | 页面上直接点「下载极简档 / 全量档」，带进度条 |
| 4 ComfyUI 服务 | 服务在不在跑、节点加载了没 | 点一下「启动 ComfyUI」，它自己起，起不来会告诉你日志尾巴 |
| 5 试画一张 | 真的画一张 512 的小图 | 失败会按原因给不同修法（爆显存 / 缺模型 / 服务掉了） |
| 6 保存位置 | 输出目录能不能写 | 提示换成哪个目录，或者直接帮你打开它 |

每一步都只有三种状态：**✓ 通过了**（可以安心下一步）、**! 注意**（能用，但有前提）、**× 还没通过**（照着「怎么改」点就行）。没通过的步骤不会让你继续往下走，所以不会出现「一路点完才发现跑不起来」。

> 想跳过：右上角「跳过，直接用」；或者在地址后面加 `?nowizard=1`。

### ① 角色
- 填资产名称 + 角色提示词，选候选数量（2/4/6/8），点 **「✦ 批量出候选图」**
- 候选图画廊出现后，**点击选中一张**（✓ 高亮）用于生成动作
- 也可以直接**拖入图片**当角色图
- 候选图不满意可点右上角 × 丢弃、或「全部清空」释放内存
- 候选区最前面那格绿框的 **「✓ 当前角色」** 就是这次生成要用的图：点左侧已保存资产时会自动切成该资产的角色图

### ② 动作
- 多选动作（站立/行走/攻击…），点 **「▶ 生成动作」**
- **输出方式**：默认「像素动画」（逐帧量化 + 最近邻放大）；切到 **「原画帧」** 就跳过像素化，直接输出视频原帧（864×480 起，透明背景），更快也更清晰，适合自己做后期或直接进游戏引擎缩放
- **「＋ 自定义动作」** 输入的名字会真正加进栏目（并自动勾选），下次打开界面还在（存在 `输出\_动作库.json`）
- 每个动作标签**悬停时右侧出现 ×**，可把它从栏目里移除；叉错了点右上角 **「恢复默认动作」** 补回
- 选中已保存资产后，它已有的动作会带 **绿点** 标记（同名再生成会覆盖旧帧）

### ③ 待你确认
- 生成结果先出现在「待你确认」区（带动画预览），**点「接受并保存」才写入硬盘**，点「丢弃」则内存直接释放
- 临时下载：待确认的结果也能直接下载 PNG 序列 ZIP（不落盘）

### ④ 已保存的动画
- 透明背景动画播放器（8/12/24 FPS、1×~6× 缩放）、逐帧条、下载 ZIP
- 动作标签（tab）右侧悬停出现 **×** → 只删这一个动作
- 左侧资产卡右侧悬停出现 **×** → 删除整个资产（角色图 + 全部动作），动作删光了的资产也能这样清理
- 点左侧任意资产 = 把它的角色图载入候选区 + 补上它的动作栏目，**可以直接接着生成新动作**
- 点 **「＋ 新建」** 清空当前角色，开始做下一个角色（不会动已保存的资产）

## ⑤ 挂机模式（排队无人值守）

界面最下面那张卡：**列好队列 → 点「执行队列」→ 剩下的全自动**，不需要中途点确认。

- **输出目录可换**：点「📁 浏览…」选任意盘 / 文件夹（也可以用系统「新建文件夹」按钮当场建），
  选完立即生效并记住；「打开」直接开资源管理器，「用默认」恢复成 `MyPixelTool\输出`
  - 目录不可写（比如选了只读盘、网络盘断线）会当场报错，不会跑到一半才失败
- **动作序列**：直接用第 ② 步勾选的动作，改那边这里会同步（`n 个资产 × m 个动作 = n×m 个输出`）
- **三种录入方式**
  1. 点「＋ 新增」一条条填
  2. 点「批量粘贴」一次贴一堆，支持这些写法混用：
     ```
     【资产名称：骑士A。提示词：像素风骑士，蓝披风，正面站立。】
     【资产名称：法师B。提示词：像素风法师，紫袍，手持法杖。】
     资产名称：弓箭手C 提示词：像素风弓箭手，绿色斗篷
     骑士D | 像素风骑士，银色铠甲
     ```
  3. 只贴提示词（没名称的行会留空，需要你补一下名称）
- **执行逻辑**：每个资产 → 出 1 张图（**无脑取第一张**）→ 当角色图存盘 → 依次跑完动作序列 → **每个动作生成完立刻落盘**，
  不等确认。中途某个资产失败（提示词为空、显存不足等）会**跳过它继续下一个**，失败清单写在日志里
- **进度**：百分比 + `已完成 X / Y 个动作` + 滚动日志；「■ 停止」是当前这一步做完才停（不会写坏文件）
- **同名资产会覆盖**同名的动作目录（角色图也一起换），所以想保留旧结果就换个名字

## 内存暂存（护盘机制）

- ComfyUI 侧装了 `custom_nodes\pixel_memory` 节点：所有生成结果（候选图、视频帧、遮罩）**只存在内存**，全程不写文件
- 只有「接受保存」那一刻才写硬盘；丢弃 = 内存直接释放，硬盘零磨损
- 内存池上限 3GB、3 小时未访问自动回收；重启 ComfyUI 会清空未接受的候选图（已接受的不受影响）

## 命令行（可选，生成后直接落盘）

```bat
..\comfyui内置环境包\python.exe -s pipeline.py --name 小骑士 --prompt "…" --actions 站立 攻击
..\comfyui内置环境包\python.exe -s pipeline.py --name 小骑士 --image D:\角色图.png --actions 攻击
```

常用参数：`--duration`（秒）、`--pixel`（32~128）、`--steps`（4~8）、`--video-size`（32 的倍数）、`--keep-video`

## ComfyUI 服务

- 生成时会**自动启动** ComfyUI（端口 8188），跑完留在后台供下次复用
- 如果提示「缺少内存暂存节点」，先关掉旧的 ComfyUI 窗口再重新生成

## 实测性能（RTX 5060 Laptop 8GB）

- 批量候选图：每张约 80~90 秒
- 单动作全链路（1.5 秒 640×352）：约 4~5 分钟，39 帧成品

## 目录结构

```
draw_tool\
├── MyPixelTool\           ← 工具本体（本目录：网页界面 + 流水线脚本）
├── ComfyUI\               ← 推理后端（含 custom_nodes\pixel_memory 内存节点）
├── comfyui内置环境包\      ← Python 3.11 + PyTorch（cu130）
├── models\                ← 模型权重，按子目录分类（约 64GB）
└── 分享包\                ← 打包好的分享 zip 放这里
```

之前的 PixelSmith 程序（pixelsmith.exe / runtime / env-pack 压缩包）已经删除——它唯一有用的
ComfyUI 目录已搬到顶层，其余都是它自己的壳和重复的 3GB 环境包。

## 几个维护脚本

| 脚本 | 用途 |
|---|---|
| `硬件检测.bat` | 体检：显卡/显存/内存/磁盘/模型齐全度，直接给出"这台机器适合哪档"的结论 |
| `启动网页界面.bat` | 本机使用，只监听 127.0.0.1 |
| `启动服务端(局域网).bat` | 局域网共享，监听 0.0.0.0 并打印其他设备可用的地址 |
| `一键安装.bat` | 全新机器从零装到能跑（clone ComfyUI → 装依赖 → 下载模型 → 联接），fork 者用 |
| `下载模型.bat` | 按 `models\manifest.json` 下载/校验模型（断点续传）；双击时可选 lite / full / auto 档位 |
| `初始化模型目录.bat` | 把 `..\models\` 下的模型目录**联接**进 `ComfyUI\models\`（不复制文件、不占双份空间） |
| `打包分享.bat` | 生成 `..\分享包\像素动画工坊-<日期>.zip`（约 20MB，含工具 + ComfyUI，不含模型/作品/Python 环境） |

模型清单在 `models\manifest.json`（文件名/字节数/SHA256/官方来源），`download_models.py` 依它工作；
GitHub 仓库的 README 也是按这个清单写的，两边保持一致。

## 配置不够怎么办（重要）

**先双击 `硬件检测.bat`**，它会直接告诉你这台电脑能跑什么、该装哪档模型、还差什么。不用自己猜。

三档配置，对应三种用法：

| 你的电脑 | 怎么用 |
|---|---|
| 有 NVIDIA 显卡 8GB+ | 本机全功能。装全量档模型 |
| 有 NVIDIA 显存 4~6GB | 本机只能出**静态像素图**（装极简档 15GB）。想要动画走下面的局域网方案 |
| 没有独显（核显本） | **别在本机硬跑动画**——社区结论是"慢到基本不可用"。用下面的局域网方案，只开浏览器就行 |

### 局域网共享：一台显卡机，所有人用

1. 在有显卡的那台电脑上双击 **`启动服务端(局域网).bat`**
2. 窗口会打印：
   ```
   本机访问    http://127.0.0.1:8899
   其他设备    http://192.168.1.23:8899
   ```
3. 把「其他设备」那行地址发到微信/群里，别人用**浏览器**打开就行——手机、平板、核显本都可以，**什么都不用装**，功能和主机上一模一样（出图、动画、挂机全有）
4. 首次启动 Windows 可能弹防火墙提示，必须点**允许访问**，否则别人连不上

> 同一 WiFi 下的人都能打开、也能删资产，别在公共网络里开。

### 极简档 ↔ 全量档

- 只想出图：双击 `下载模型.bat` 选 `[1] lite`（15GB）
- 想加动画：再双击 `下载模型.bat` 选 `[2] full`，只会补下缺的 53.6GB
- 程序会**自动用你实际装了的模型**，装完重启界面，右上角档位标签会变

## 注意

- 视频时长会对齐到模型的 17k+5 帧网格（2 秒 → 56 帧）
- 8GB 显存靠内存卸载运行；生成时尽量关掉占显存的程序
- 极简档只装了出图模型，动作和挂机出动画的入口会提示"未装动画模型"

## 显存保护（已内置）

- 去背景改为**分块处理**（每块 8 帧），不再一次性把 50+ 帧全塞进显存
- 每次去背景前自动调用 ComfyUI 的 `/free` 接口，**把视频模型从显存卸载**再加载抠图模型
- 某一块仍然显存不足时，自动**减半块大小重试**（8 → 4 → 2 帧），无需人工干预
- 如果还是报 out of memory：关掉正在占用显存的程序（游戏、开了硬件加速的浏览器标签等）再试
